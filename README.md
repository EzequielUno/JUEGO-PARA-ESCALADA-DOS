<h1> JUEGO DE ESCALADA PARA INFANTILES </h1>

<p>Se trata de una app que arma vías de escalada.</p>

<img src="/images/inicio.png" alt="inicio"></img>

<p>Según el nivel de complejidad, la app selecciona sectores y distintos tipos de tomas para armar una vía y escalar.-</p>

<p>Si el participante cumple con la consigna de la vía, suma puntos. Caso contrario no suma puntos.-</p>

<img src="/images/desafio.png" alt="desafío"></img>

<p>Los niveles de dificultad son 3:</p>

<ul>
<li>Principiante - Muro Amigable</li>
<li>Intermedio - Desafío</li>
<li>Avanzado - Desplome Loco</li>
</ul>

<p>La cantidad de tomas y los tamaños, varían según el nivel de dificultad seleccionado.-</p>
